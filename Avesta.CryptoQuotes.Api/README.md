# Crypto Quotes API

A simple ASP.NET Core Web API built as part of a technical assignment to retrieve the latest exchange rates for a given cryptocurrency against multiple currencies.

## Tech Stack
- ASP.NET Core Web API
- CoinMarketCap API
- ExchangeRates API

## How to Run
1. Configure API keys in `appsettings.json`
2. Run the application using: dotnet run

## Notes
- The implementation focuses on the requirements described in the assignment.
- Additional concerns such as caching or persistence were intentionally left out.
